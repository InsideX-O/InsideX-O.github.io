# XBot — интерактивный макет

Публичная статическая копия для просмотра макета. Главная страница открывает тестовый стенд; все данные демонстрационные, изменения остаются в браузере и ничего не отправляется.

Редактируемые исходники хранятся отдельно от этого публичного репозитория. Пересобрать локальную публикацию: `python tools/build-github-pages.py`.
