# XBot — интерактивный макет

Статическая GitHub Pages копия дизайн-макета. Главная страница открывает тестовый стенд; все данные демонстрационные, изменения остаются в браузере и ничего не отправляется.

Исходники макета находятся в `web/index.html`, `tools/stand.js` и `web/stand/`. Пересобрать локальную публикацию: `python tools/build-github-pages.py`.
